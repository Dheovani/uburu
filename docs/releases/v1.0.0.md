# Uburu 1.0.0

Uburu 1.0.0 is the first stable release of the local search application for Windows and Linux. It promotes the 0.1 preview foundation after cross-platform validation, correctness hardening, bounded resource enforcement, and real-world testing against multi-gigabyte document corpora and source repositories.

## Highlights

- Fast recursive direct, indexed, and hybrid search with progressive results and cooperative cancellation.
- Literal, Unicode-aware, whole-word, file-name, extension, glob, size, hidden-file, binary-file, `.gitignore`, and PCRE2 regex filtering.
- Content extraction and occurrence-aware preview for PDF, OOXML, OpenDocument, RTF, HTML/XHTML, subtitles, and plain text.
- Persistent SQLite indexing with catalog, content-hash, and Git blob-hash reuse, atomic generations, recovery, staleness detection, and explicit memory/disk budgets.
- Git-aware repository, branch, detached-HEAD, worktree, overlay, ignored/untracked/modified/deleted, submodule, and reconciliation behavior.
- Responsive Qt/QML desktop interface with scope history, favorites, saved searches, themes, English/Portuguese translations, command palette, settings, metrics, indexing progress, preview highlighting, and file actions.
- `uburu` CLI with direct/indexed/hybrid strategies, JSON Lines, stable exit codes, streaming output, index commands, and `Ctrl+C` cancellation.

## Stable-release hardening

- Direct file processing now uses bounded, hardware-aware parallelism while preserving deterministic publication and backpressure.
- Direct validation is authoritative in hybrid search, preventing stale indexed results from surviving final refinement.
- Search-result and indexing working-memory budgets are enforced and exposed through the desktop and CLI.
- PDF extraction was hardened for Unicode paths, embedded null bytes, glyph spacing, ligatures, indirect font resources, and page-specific preview selection.
- Windows and Linux Release builds were validated against a real multi-gigabyte PDF corpus; direct, indexed, and hybrid strategies converged on the known result.
- Disposable Git/CLI validation covered modified, untracked, ignored, deleted, branch-specific, detached-HEAD, and isolated worktree states.

## Artifacts

- Windows x64 installer generated with Inno Setup.
- Windows x64 portable ZIP.
- Linux x86-64 AppImage.
- SHA-256 checksums, SPDX SBOM, third-party notices, and release asset manifest.

## Compatibility

The storage, indexed-document, settings, and CLI contracts are versioned. Existing 0.1 user state is validated through the migration and recovery paths; uninstalling Uburu preserves user settings, history, and indexes unless they are removed explicitly.

## Known limitations

- Windows artifacts are not Authenticode-signed because no code-signing certificate is currently available.
- Protected, malformed, unsupported, and safety-limited documents may remain name-searchable while content extraction is unavailable.
- macOS and Flatpak are not supported release targets for 1.0.
- Legacy binary Office formats, email containers, OCR/image-content search, and automatic update transport remain future work.

See `CHANGELOG.md`, `docs/releases/v1.0.0-end-to-end-observations.md`, and the platform validation records for detailed evidence.
